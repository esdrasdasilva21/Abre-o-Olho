# Abre o Olho
**Open-Source Virtual Reality and Digital Interaction**

Open-DoVision was used as a technological reference and exploration platform in the development of the **Final Project for the Multimedia Production course**, with the aim of studying and exploring the possibilities of integrating virtual reality, human-computer interaction, and multimedia technologies.

The project features two main functionalities:

- **USB-Mouse:** Transforms Open-DoVision into a virtual mouse-like control device, enabling interaction with applications and games through movements in physical space.
- **USB-HID:** Allows Open-DoVision to function as a Human Interface Device (HID), capable of sending and receiving data from a computer.

The USB-Mouse module provides a practical introduction to the use of virtual reality in applications and games that were not originally designed for three-dimensional environments.

The USB-HID module, on the other hand, includes a small desktop application that demonstrates the communication and interaction mechanisms between the device and the computer system.

**Academic and Technological Relevance**

Exploring this project provided an opportunity to develop knowledge and practical skills in virtual reality, interaction devices, hardware-software communication, and the development of interactive multimedia experiences.

Open-DoVision therefore served as an important reference for understanding how open-source technologies can be applied to the creation of innovative solutions in the field of Multimedia Production.
